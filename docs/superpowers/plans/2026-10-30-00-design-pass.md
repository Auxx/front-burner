[The design](../specs/2026-10-30-islands-design-pass-design.md) is the spec. It
makes every implemented page look like JetBrains' Islands theme on a desktop in
dark mode, and replaces the layout and typography each page copies with shared
pieces. This index splits it into small plans, numbered on from 33
([the step 2 index](2026-10-28-00-roadmap-step-2.md)). Each plan is one branch
and one pull request, leaves CI green, and can be shown to someone when it is

## Shared constraints

The shared constraints of [the step 2 index](2026-10-28-00-roadmap-step-2.md)
apply, with these additions:

- **Tokens only.** Components and pages read semantic or component tokens; no
  colour, size or duration is written as a literal outside the token files (A-10
  token tiers). A new surface or size is a new token with light and dark values.
- **Light mode and narrow screens keep working.** Light values of existing
  tokens do not change unless a task says so. Every page still works at 320 CSS
  px without sideways scrolling (NF-12.4). Neither is tuned in this pass.
- **Contrast.** `npx nx run ai-tools:test` (the `ui-contrast` spec) passes after
  every token change; pairs that pass by less than 2 % are confirmed on the
  Storybook token page (`ai-tools` skill, `tokens`).
- **No layout shift**: no element moves when a link becomes active, a panel
  opens or a banner grows.
- **Accessibility kept**: route focus on the page's `h1`, landmarks,
  `aria-current`, forced colours (A-10.22), reduced motion (motion tokens drop
  to 0).
- **No new runtime dependency.** New Codicons go through `icons.mjs` (`ai-tools`
  skill, `icons`).
- **Docs in the same pull request**: each plan updates the requirement and
  architecture text its tasks name, then runs `node
  tools/ai-tools/src/bin/doc-ids.mjs check`.
- **Visual check of record**: each task that changes the look ends with a
  screenshot of the agreed state, compared with the mockup the design names (in
  `.superpowers/brainstorm/81844-1793383165/content/`). Use `story.mjs` for
  `libs/ui` stories and the running web client (`nx serve web`, dark mode, 1440
  × 900) for pages.
- Verify with `npx nx affected -t lint,test,build` before each pull request and
  format with `npx nx format:write` (development-workflow skill).
