# Git Engine over HTTPS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Plan 7 of [the index](2026-10-26-00-roadmap.md): the backend can check
access to an HTTPS remote and clone it, fully or as a single branch, anonymously
or with a username and token, with every connection going through the egress
proxy and no secret on a command line, in a URL, in an environment variable or
in a file.

**Architecture:** A new `server/core/git` library, ported from the two spikes
(`spike/ssh-credential-broker`, `spike/egress-proxy`) into typed NestJS code.
`GitRunner` spawns `git` with a clean environment and the A-5.1 hardening. For
each network command a **broker** opens a `0700` directory with two Unix
sockets: the askpass socket (A-5.4) and the SOCKS5 egress proxy (A-5.7), both
guarded by the command's one-time token. `GitEngine` offers operations, not
command lines (A-5.10): `accessCheck` and `clone` in this plan. Plan 8 adds SSH
to the same broker.

**Tech Stack:** as before; `git` 2.47 or later on the host (A-5.7). No new
packages.

**Spec:** `docs/architecture/git-engine.md` A-5.1, A-5.2, A-5.4 (HTTPS), A-5.7
to A-5.10, A-5.13; `docs/requirements/repo-add.md` AR-17, AR-22, AR-36, AR-42,
AR-43, AR-49 (git part), AR-50, AR-51, AR-57;
`docs/architecture/non-functional.md` NF-5.3, NF-10.5, NF-11.6 to NF-11.8;
`docs/architecture/overview.md` A-1.15. Spikes: `docs/architecture/spikes.md`
spikes 1 and 2, and their branches.

## Global Constraints

- The shared constraints of [the index](2026-10-26-00-roadmap.md) apply.
- Uses plan 3's `resolveAllowed`, `EgressRefusedError`, `EgressOptions`, and
  `startHttpsTestServer`'s certificate; plan 3's `ParsedRemote` and
  `parseRemoteUrl`.
- Port the spikes' behaviour, not their files: typed, one responsibility per
  file, NestJS providers where state is shared. Keep the spikes' protocol
  details exactly (SOCKS5 greeting, username/password auth with user `fb` and
  the token as password, `CONNECT` only; askpass request as one JSON line `{
  token, prompt }`, answer `ok <value>\n`).
- `git` runs with `-c protocol.allow=never -c protocol.https.allow=always -c
  protocol.ssh.allow=always -c core.hooksPath=/dev/null -c core.autocrlf=false
  -c submodule.recurse=false -c credential.helper=` on every call, and for
  clones also `-c filter.lfs.smudge= -c filter.lfs.process= -c
  filter.lfs.required=false` (AR-50). The environment is built from scratch
  (A-5.1); from the backend's own environment only `GIT_SSL_CAINFO`,
  `SSL_CERT_FILE` and `SSL_CERT_DIR` are passed through when set _(plan's call:
  how an operator with a private certificate authority points git at it, AR-43;
  tests use it for their own certificate)_.
- Everything git writes to stderr goes to the log only after
  `redactCredentials`, and only at `debug` with the remote URL (NF-10.5).
- New variables (A-1.15): `FRONT_BURNER_CLONE_TIMEOUT` (default `30m`) and
  `FRONT_BURNER_GIT_TIMEOUT` (default `5m`), durations as in LG-62.

## Review Focus

- **The token appearing anywhere outside the backend process** while git runs:
  in git's or its children's command lines or environments, in a file in the
  broker directory or the working copy → Task 4 test `keeps the password out of
  git's arguments, environment and files` (sample `/proc/<pid>/cmdline` and
  `environ` of every descendant while a clone waits on the server, as spike 1
  did; scan the clone and broker directory afterwards).
- **An HTTPS remote that redirects to another host** must get no credentials for
  the other host, and a redirect to a blocked address must fail as unreachable →
  Task 3 test `answers prompts only for the expected host` and Task 4 test
  `refuses a redirect to a blocked address`.
- **A working copy whose `.git/config` holds `url.*.insteadOf` or a proxy
  setting** must make network commands refuse to run, not silently go around the
  proxy → Task 3 test `refuses a repository config that bypasses the proxy`.
- **A clone that fails or times out half-way** must leave neither a partial
  working copy at the destination nor a directory in `tmp/` (AR-53, NF-5.3) →
  Task 4 tests `leaves nothing behind when a clone fails` and `stops a clone at
  the timeout`.
- **git's stderr echoing a URL with credentials** (a server that puts them in a
  redirect, a user name in an scp-like URL) must be logged without them → Task 1
  test `removes credentials from URLs in git's output`.

### Task 1: `server/core/git` and the git runner

**Files:**

- Create (generated): `libs/server/core/git` with `npx nx g @nx/nest:library
  --directory=libs/server/core/git --name=server-core-git
  --importPath=@front-burner/server-core-git --unitTestRunner=vitest --strict
  --tags=scope:server,type:core --no-interactive`
- Create: `src/runner/git-runner.ts` (+ `.spec.ts`), `src/runner/redact.ts` (+
  `.spec.ts`), `src/runner/git-version.ts` (+ `.spec.ts`)

**Interfaces:**

- Produces:
  - `redactCredentials(text: string): string` — replaces the user info of every
    `scheme://user[:password]@` in the text with `***@`.
  - `GitRunOptions = { cwd?: string; env?: Record<string, string>; timeoutMs:
    number; maxOutputBytes?: number (default 1 MiB); stdin?: string }`.
  - `GitResult = { exitCode: number | null; stdout: string; stderr: string;
    timedOut: boolean }` (`stderr` already redacted).
  - `GitRunner` (injectable): `run(args: string[], options: GitRunOptions):
    Promise<GitResult>` — `spawn('git', [...HARDENING, ...args])` with
    `detached: true`; environment: `PATH` (the Node binary's folder,
    `/usr/local/bin:/usr/bin:/bin`), `HOME` = a fresh `0700` directory removed
    afterwards, `GIT_CONFIG_NOSYSTEM=1`, `GIT_CONFIG_GLOBAL=/dev/null`,
    `GIT_TERMINAL_PROMPT=0`, `LC_ALL=C`, the pass-through CA variables, then
    `options.env`; on timeout kills the process group with `SIGKILL` (A-5.1);
    stops reading past `maxOutputBytes`. `killAll(): Promise<void>` kills every
    running group (A-1.14, called on shutdown).
  - `gitVersion(runner): Promise<[number, number, number]>` and
    `assertSupportedGit(runner): Promise<void>` — throws when git is missing or
    older than 2.47.0 (A-5.7).

### Task 2: The egress proxy

**Files:**

- Create: `libs/server/core/git/src/egress/egress-proxy.ts` (+ `.spec.ts`)
- Create: `libs/server/core/git/helpers/proxy-connect.cjs` (ported from
  `spike/egress-proxy/lib/proxy-connect.js`; plain Node, no imports but
  `node:net`)

**Interfaces:**

- Consumes: `resolveAllowed`, `EgressOptions` (plan 3).
- Produces:
  - `openEgressProxy(options: { socketPath: string; token: string; egress:
    EgressOptions; lookup?: Lookup; connectTimeoutMs?: number (default 15 000)
    }): Promise<EgressProxy>` — SOCKS5 on the Unix socket, username `fb` and the
    token as password (compared with `constantTimeEquals`), `CONNECT` with a
    domain name or an address only; resolves with `resolveAllowed`, connects to
    the checked addresses only (one after the other, first success wins),
    `setNoDelay(true)` on outgoing sockets (A-5.7, A-5.8).
  - `EgressProxy = { refusals: EgressRefusal[]; close(): Promise<void> }` with
    `EgressRefusal = { host: string; reason: 'invalid-host' | 'not-found' |
    'blocked' | 'unreachable' }`; the engine uses `refusals` to tell an egress
    refusal from other failures.

      client (spawned with `FB_EGRESS_SOCK`, `FB_BROKER_TOKEN`,
      `FB_EGRESS_TARGET`) against a local TCP echo server: `relays to an allowed
      address`; `refuses a wrong token`; `refuses a blocked address and records
      it` (`egress: { blockPrivateNetworks: true }`, target `127.0.0.1:<port>` →
      refusal `blocked`); `refuses a name with a blocked address` (fake lookup);
      `records an unreachable host` (a closed port).
- [ ] **Step 2: Run them and see them fail** — `npx nx test server-core-git`.

### Task 3: The broker, askpass and the repository config check

**Files:**

- Create: `libs/server/core/git/src/broker/broker.ts` (+ `.spec.ts`)
- Create: `libs/server/core/git/helpers/askpass.cjs` (ported from
  `spike/ssh-broker/lib/askpass.js`)
- Create: `libs/server/core/git/src/config/repository-config.ts` (+ `.spec.ts`)
- Create: `libs/server/core/git/src/git.options.ts`

**Interfaces:**

- Consumes: `openEgressProxy` (Task 2), `GitRunner` (Task 1).
- Produces:
  - `GIT_OPTIONS = 'FRONT_BURNER_GIT_OPTIONS'`, `GitOptions = { helpersDir:
    string; egress: EgressOptions; cloneTimeoutMs: number; gitTimeoutMs: number
    }`.
  - `GitCredentials = { kind: 'none' } | { kind: 'https'; username: string;
    password: string }` (plan 8 adds `ssh`).
  - `openBroker(options: { remote: ParsedRemote; credentials: GitCredentials;
    gitOptions: GitOptions; lookup?: Lookup }): Promise<Broker>` — creates a
    `0700` directory under `os.tmpdir()` named `fb-broker-*`, a 32-byte
    base64url token, the egress proxy on `<dir>/p`, and for HTTPS credentials
    the askpass server on `<dir>/a`.
  - `Broker = { env: Record<string, string>; egress: EgressProxy; close():
    Promise<void> }`. `env` holds `GIT_CONFIG_COUNT`/`KEY_n`/`VALUE_n` for
    `http.proxy=socks5h://fb:<token>@localhost<dir>/p` (A-5.7: off the command
    line), and with HTTPS credentials `GIT_ASKPASS=<helpersDir>/askpass.cjs`,
    `FB_BROKER_SOCK`, `FB_BROKER_TOKEN`. `close()` stops the servers and removes
    the directory.
  - The askpass server answers at most 4 prompts per command, and only `Username
    for 'https://<host>[:port]': ` and `Password for
    'https://<user>@<host>[:port]': ` for the remote's own host and port and the
    expected user name (A-5.4); anything else is refused and recorded.
  - `assertSafeRepositoryConfig(runner, cwd): Promise<void>` — throws
    `UnsafeRepositoryConfigError` (listing the keys, no values) when the local
    or worktree config, includes followed, has any key of A-5.7's list.
  - `assertHelpersExecutable(helpersDir): void` — both helpers exist and pass
    `accessSync(X_OK)`.

- [ ] **Step 1: Write the failing tests**: broker `creates a private directory
      and removes it` (mode `0700`, gone after `close`); `answers git's prompts`
      (run `askpass.cjs` with the two prompts → username, password); `answers
      prompts only for the expected host` (a prompt for another host, or another
      user, is refused); `refuses a forged token`; `answers at most 4 prompts`;
      config `refuses a repository config that bypasses the proxy` (one test per

      `url.x.pushInsteadOf`, `include.path`, `includeIf.gitdir:/.path`,
      `http.curloptResolve`) and `accepts a clean config`.
- [ ] **Step 2: Run them and see them fail** — `npx nx test server-core-git`.
- [ ] **Step 3: Implement**, porting `broker.js` (HTTPS half) and

### Task 4: Access check and clone over HTTPS

**Files:**

- Create: `libs/server/core/git/src/engine/git-engine.ts` (+ `.spec.ts`),
  `src/engine/git-errors.ts` (+ `.spec.ts`), `src/git.module.ts`
- Create: `libs/server/core/git/src/testing/git-http-server.ts` (exported from
  `@front-burner/server-core-git/testing`, path alias in `tsconfig.base.json`)
- Modify: `libs/server/core/config/src/config/*` (+ spec) for the two timeouts
- Modify: `docs/architecture/git-engine.md` A-5.1 (the CA pass-through) and
  A-5.10 (the access check's result)

**Interfaces:**

- Consumes: Tasks 1 to 3, `Config.cloneTimeoutMs`, `Config.gitTimeoutMs`,
  `Config.blockPrivateNetworks`.
- Produces:
  - `GIT_ERROR_CODES = ['host-unreachable', 'timeout', 'tls-untrusted',
    'auth-failed', 'repository-not-found', 'branch-not-found',
    'host-key-unknown', 'host-key-changed', 'unsafe-repository-config',
    'failed']`; `class GitOperationError extends Error { code: GitErrorCode;
    detail: string (redacted stderr); params: Record<string, string> }`.
    `host-key-*` are produced in plan 8.
  - `classifyGitFailure(result: GitResult, refusals: EgressRefusal[]):
    GitErrorCode` — in order: `timedOut` → `timeout`; any egress refusal →
    `host-unreachable` (AR-57: the same as an unreachable host); stderr `SSL
    certificate problem` or `server certificate verification failed` →
    `tls-untrusted`; `Could not resolve host`, `Failed to connect`, `Connection
    refused`, `Couldn't connect to server` → `host-unreachable`; `Repository not
    found`, `The requested URL returned error: 404`, `does not appear to be a
    git repository` → `repository-not-found`; `Authentication failed`, `could
    not read Username`, `could not read Password`, `The requested URL returned
    error: 40[13]`, `Invalid username or (password|token)` → `auth-failed`;
    `Remote branch .* not found` → `branch-not-found`; else `failed`. The
    patterns live in this one file (RC-5).
  - `AccessCheckResult = { branches: string[]; defaultBranch: string | undefined
    }` — branch names sorted with `localeCompare`; empty for an empty remote
    (AR-37).
  - `GitEngine` (injectable, from the global `GitModule.forRoot(options:
    GitOptions)`):
    - `accessCheck(remoteUrl: string, credentials: GitCredentials):
      Promise<AccessCheckResult>` — `git ls-remote --symref <url> HEAD
      'refs/heads/*'` through a broker, timeout 30 s (AR-42); throws
      `GitOperationError`;
    - `clone(request: { remoteUrl: string; credentials: GitCredentials; mode:
      CloneMode; branch?: string; tmpRoot: string; destination: string }):
      Promise<void>` — clones into a fresh directory under `tmpRoot` (`git clone
      --no-recurse-submodules [--single-branch --branch <b> --depth 1] --
      <url> <dir>`, timeout `cloneTimeoutMs`, AR-49 to AR-51), runs
      `assertSafeRepositoryConfig` on the result, then `rename`s it to
      `destination` (A-5.13, NF-5.3); on any failure removes the temporary
      directory and throws.
    - `beforeApplicationShutdown` calls `GitRunner.killAll()`.
  - `startGitHttpServer(options: { repositories: Record<string, string>; users?:
    Record<string, string> }): Promise<{ url: string; ca: string; close() }>` —
    an HTTPS server with the test certificate that runs `git http-backend` as
    CGI for bare repositories, with Basic authentication when `users` is given.

- [ ] **Step 1: Write the failing tests** (`process.env.GIT_SSL_CAINFO` set to
      the test certificate for the run; fixtures are bare repositories created
      in a temporary folder with `main` and `feature/x`):
  - `lists the branches and the default branch`; `checks an empty remote`
    (`branches: []`);
  - `clones every branch` (`git branch -r` lists both) and `clones a single
    branch at depth 1` (`git rev-list --count HEAD` is 1, only `main`);
  - `checks access with a username and token`; `reports wrong credentials as
    auth-failed`; `reports a missing repository as repository-not-found`;
    `reports a private repository without credentials as auth-failed`;
  - `reports an untrusted certificate` (`GIT_SSL_CAINFO` unset for one test);
  - `reports a closed port as host-unreachable`; `refuses loopback with the
    switch as host-unreachable`; `refuses a redirect to a blocked address` (the
    server answers `302` to `https://169.254.169.254/x`);
  - `reports a missing branch as branch-not-found`;
  - `leaves nothing behind when a clone fails`; `stops a clone at the timeout`
    (a server that stalls, `cloneTimeoutMs: 500`);
  - `keeps the password out of git's arguments, environment and files`.
- [ ] **Step 2: Run them and see them fail** — `npx nx test server-core-git`.
