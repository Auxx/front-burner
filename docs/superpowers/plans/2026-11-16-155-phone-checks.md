# Phone Hand Checks Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Plan 155 of [the step 6 index](2026-11-16-00-roadmap-step-6.md): the
web client is checked by hand on a real iPhone and a real Android phone before
the release (NF-12.2): every MVP page by touch alone (NF-12.5), the editor with
the on-screen keyboard open, portrait and landscape (NF-12.6), and typing speed
in large files, including with the conflict view (NF-2.4, `docs/wiki/
typing-test.md`; the step 4 index's leftover).

**Architecture:** A hand check. **The operator holds the phones**; the agent
writes the script and turns the results into records and fixes. The script, in
`docs/wiki/release-checks.md`'s "Phones" section, is a numbered list that a
person follows with one phone in hand, each line one action and its expected
result, grouped by exit criterion (3 to 11), against an instance served over
HTTPS (the guide's setup, plan 140). Typing uses `typing-test.mjs`'s page with
the remote inspector (Safari's Web Inspector, Chrome's `chrome://inspect`), as
`typing-test.md` describes, at 200 KB and 1 MB, with and without
`?conflicts=on`.

**Tech Stack:** `tools/ai-tools/src/bin/typing-test.mjs`.

**Spec:** `docs/architecture/non-functional.md` NF-2.4, NF-12.2, NF-12.4 to
NF-12.6, NF-13.5; `docs/wiki/typing-test.md`; `docs/architecture/web-client.md`
(the conflict view's phone check).

## Global Constraints

- The shared constraints of [the step 6 index](2026-11-16-00-roadmap-step-6.md)
  apply.
- Each result records the phone model, OS version and browser version.
- The script includes the pages added since the last phone check: the repository
  management and settings pages and their dialogs (the step 5 index's leftover),
  the low-space banner (plan 132) and the storage-full save status (plan 133).
- A failure is a plan (index, Part F) unless it is a one-line fix.

## Review Focus

- **The on-screen keyboard hiding the editor's toolbar or caret** (NF-12.5) → a
  script line for each orientation.
- **Touch targets under 44 px** (NF-13.5) on the settings page's dense rows → a
  script line that taps each.
- **iOS Safari's zoom on focus** of inputs under 16 px → a line on each form.
