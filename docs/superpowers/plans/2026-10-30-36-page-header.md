# Full-Island Pages and Header Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Plan 36 of [the design pass index](2026-10-30-00-design-pass.md): the
Dashboard and Add repository pages are one island filling the screen below the
header, with a one-line title bar (ancestors, then the page's `h1`) at the top.
The app header has room above it, wider gaps, a plain **Dashboard** link with no
icon, and a bold active link that never shifts its neighbours. Recent
repositories are tiles.

**Architecture:** A new `libs/ui` layout, `ui-page`, owns the island, the title
bar and an optional centred column; it reuses `*uiBreadcrumb` for ancestors and
takes the page's own `h1` by content projection, so route focus (`main h1` in
`shell-layout`) still works. `ui-breadcrumbs` loses its last user and is
removed. Header changes are in `web/shell`.

**Tech Stack:** as plan 35.

**Spec:** [design](../specs/2026-10-30-islands-design-pass-design.md) G2 (copies
on these pages), G4, G5, Shared layouts 2, Per page: Dashboard, Add repository.
NV-5, NV-6, NV-9, NV-14.

## Carried over from plan 34

In dark mode `surface-raised` equals `surface-canvas` (neutral-27): accent
(blue-55) on raised fails 3:1 at any lighter step (28: 2.91, 29: 2.82, 30:
2.71). The app header's user-menu button, and secondary and icon buttons on the
canvas, therefore rely on `border-default` only. This plan must decide on a
dedicated token or an accent change.

## Global Constraints

- The shared constraints of [the index](2026-10-30-00-design-pass.md) apply.
- Title bar: `<nav aria-label="Breadcrumb">` with only the ancestor links,
  separated by `›`, in `--ui-text-muted`; then the page's `h1` on the same line,
  `--ui-font-size-ui` (the breadcrumb size), semibold, `--ui-text-default`. The
  `h1` is never inside the `nav`. A page without ancestors renders no `nav`.
- Island content padding `--ui-space-5` block, `--ui-space-6` inline; gap under
  the title bar `--ui-space-5` _(plan's call, from the mockups)_.
- Add repository's column: **40rem**, centred, title bar and actions in it.
- Header: padding **8 px top (`--ui-space-2`), `--ui-page-padding-inline` at the
  sides**, none at the bottom; nav gap **32 px (`--ui-space-8`)**; the brand
  link reads **"Dashboard"** with **no flame icon**; the active link is
  **bold**, no header link is underlined, `aria-current="page"` stays.
- Compact brand link (narrow repository bar, NV-11): the **`home`** icon with
  the accessible name "Dashboard" _(plan's call)_.
- Tiles: `grid-template-columns: repeat(auto-fill, minmax(16rem, 1fr))`, gap
  `--ui-space-2`; each tile `--ui-surface-card`, radius `--ui-radius-popover`,
  no border, padding `--ui-space-3`.

## Review Focus

- **A repository name or remote URL with no spaces** (a 120-character URL) must
  wrap inside its tile, not widen the grid (Task 3 story or test with a long
  remote; `overflow-wrap: anywhere` stays).
- **Switching the active header link** (Dashboard → Repositories) must not move
  the other link or the user menu by a pixel (Task 2 e2e compares bounding boxes
  before and after).
- **Keyboard focus on the `h1` after navigation** must land on the title bar's
  `h1` on both pages (Task 1 test through `shell-layout`'s rule, `main h1`).
- **Add repository at 320 px**: the 40rem column shrinks to the island width
  (Task 4 screenshot).
- **One tile only** must not stretch to the island's full width beyond a
  readable size: `auto-fill` keeps empty tracks (Task 3 screenshot with one
  repository).

- Create: `libs/ui/src/layout/directives/page-title/page-title.directive.ts` (or

**Interfaces:**

- Produces: `PageComponent`, selector `ui-page`; inputs `breadcrumbsLabel =
  input<string>()` (the `nav`'s accessible name, required when there are
  ancestors) and `column = input<string | null>(null)` (a max inline size for a
  centred content column, e.g. `'40rem'`). Content: `*uiBreadcrumb` items
  (ancestors only, in order); one `h1[uiPageTitle]` projected after the `nav`;
  everything else is the page content. The island scrolls; the host fills
  `<main>`.
- Produces: `PageTitleDirective`, selector `[uiPageTitle]` (marker for the
  projection slot).
