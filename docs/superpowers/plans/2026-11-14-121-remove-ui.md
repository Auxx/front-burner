# Remove Repository Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Plan 121 of [the step 5 index](2026-11-14-00-roadmap-step-5.md): the
**Remove repository** section opens a confirmation dialog that needs one click,
or the typed name when work would be lost; after removing, the page goes to the
repository management page with "Repository _name_ removed.", and this device's
browser drafts of the repository are deleted.

**Architecture:** The dialog reads `GET /repositories/:id/removal` (plan 110)
when it opens and sends `DELETE /repositories/:id` (plan 111), with
`confirmName` when the check found work to lose. A `409
removal-needs-confirmation` (work appeared since the dialog opened) turns the
dialog into its typed-name form with the new counts, rather than failing. The
drafts are deleted through `DraftStore` by the repository's key prefix.

**Tech Stack:** as before. No new packages.

**Spec:** `docs/requirements/repo-manage.md` (RM-17 to RM-21, AC-REPO-003.11);
NF-3.3.

## Global Constraints

- The shared constraints of [the step 5 index](2026-11-14-00-roadmap-step-5.md)
  apply.
- Exact text: "Remove _name_? This deletes its working copy on Front Burner. The
  remote is not changed." (RM-17). With work to lose, a list: "_2_ uncommitted
  files", "_3_ commits not pushed", "A merge in progress", or for an unreadable
  working copy, "Front Burner can't tell whether it has work that isn't pushed."
  Then "Type _name_ to confirm" and a field; **Remove** is enabled once the
  field matches.
- **Remove** is a danger button; **Cancel** has the focus first (NF-13).
- The section is offered in every status (RM-17), with the text of RM-17 as its
  description.
- "Repository _name_ removed." is a toast on the repository management page
  (RM-20).
- `DraftStore` gains `deleteRepository(repositoryId)` if it has no such call;
  drafts claimed by another tab of the same repository are deleted too, as that
  tab goes to the dashboard (plan 122).

## Review Focus

- **No work to lose:** one click → end-to-end test `AC-REPO-003.11`.
- **Work that appears after the dialog opened** asks for the name, not a failure
  → test `asks for the name when work appeared since`.
- **Drafts** of the repository are gone from this device, and other
  repositories' drafts stay → test `deletes only this repository's drafts`.
- **A failed removal** (the network) leaves the dialog open with the error →
  test `says why removing failed`.
