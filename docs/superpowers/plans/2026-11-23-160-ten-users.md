**Goal:** Plan 160 of [the step 6 index](2026-11-16-00-roadmap-step-6.md), Part
F: fix plan 152's finding, so that NF-2.1, NF-2.2 and NF-2.6 hold on the
reference host with NF-1.2's 10 users at once. `perf-api.mjs run --users 10`
among NF-1.3's 2,500 working copies (`docs/wiki/release-checks.md`, "Reference
host") gave, p95:

| Rule   | One user | 10 users, tool on the host | 10 users, tool outside | Target           |
| ------ | -------- | -------------------------- | ---------------------- | ---------------- |
| NF-2.1 | 94 ms    | 641 ms                     | 633 ms                 | 300 ms           |
| NF-2.2 | 48 ms    | 208 ms                     | 174 ms                 | 200 ms           |
| NF-2.6 | 547 ms   | 3,691 ms (pull)            | 3,314 ms (pull)        | ≤ 1,000 ms added |
| NF-2.6 | 273 ms   | 1,506 ms (push)            | 1,933 ms (push)        | ≤ 1,000 ms added |

Running the tool from another machine changed little, so the time is the
instance's own.

**Architecture:** not known yet; Task 1 finds it. What is known:

- Each user of the tool runs its measures in a tight loop, so 10 users send far
  more requests at once than 10 people would. The rule is still "10 users active
  at the same time", and the tool is how the checklist measures it: the fix is
  in the instance, not in the tool, unless Task 1 shows that the tool measures
  something NF-1.2 does not mean. Changing the tool or the rule needs the
  operator's agreement, recorded in `non-functional.md`.
- **NF-2.6:** pulls and pushes are jobs of the `fetch` pool, which runs 4 at
  once (`jobPoolSizes` in `libs/server/core/jobs/src/runner/job-types.ts`,
  A-6.5). With 10 users, jobs wait for a place, and the wait counts as time
  added.
- **NF-2.1:** `FolderLister` describes up to 64 entries at once
  (`DESCRIBE_CONCURRENCY`); 10 listings of 1,000 entries at once share 2 vCPU
  and one event loop with the jobs' git processes.

**Tech Stack:** plan 150's `perf-api.mjs`; plan 135's metrics (`/api/metrics`:
job durations, queue depth, HTTP latency).

**Spec:** `docs/architecture/non-functional.md` NF-1.2, NF-2;
`docs/architecture/jobs.md` A-6.5.
