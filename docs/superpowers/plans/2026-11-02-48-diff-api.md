# Diff API Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Plan 48 of [the step 3 index](2026-11-02-00-roadmap-step-3.md): the
API returns one changed file's difference from the last commit, as parsed lines,
or says that it is binary or too large.

**Architecture:** `GitEngine.diff` runs git twice at most: first with 3 lines of
context, to test the 1 MB limit and to find a binary file; then, for a file
small enough, with the whole file as context, so that the client can unfold
unchanged lines without another request _(plan's call)_. A file over 1 MB whose
diff is under the limit keeps its 3-line context, and the response's `complete:
false` tells the client that its folds can't open.

**Tech Stack:** as before. No new packages.

**Spec:** `docs/requirements/git-advanced.md` (GA-14 to GA-16, the backend for
criteria 3 and 22); `docs/architecture/git-engine.md` A-5.1, A-5.10.

## Global Constraints

- The shared constraints of [the step 3 index](2026-11-02-00-roadmap-step-3.md)
  apply.
- The limit is 1 MB, that is 1,000,000 bytes of the 3-line diff (GA-16). A file
  gets whole-file context when its old and new sizes together are at most
  1,000,000 bytes.
- Every diff command passes `--no-ext-diff --no-textconv --no-color
  --no-renames`. A remote's `.gitattributes` must not choose how a diff is made.
- A tracked file: `git diff HEAD -- <path>`. An untracked one: `git diff
  --no-index -- /dev/null <path>`, where exit code 1 means "differs". Whether a
  path is untracked comes from `status`, limited to the path.
- A line-endings-only change: there is a diff, and `--ignore-cr-at-eol --quiet`
  says that there is none (GA-16). A trailing `\r` stays in the line's text, so
  that the client can show it.

## Review Focus

- **A changed file that is no longer changed** (committed in another tab)
  answers an empty diff, not an error → Task 1 test `answers no lines for an
  unchanged file`.
- **A file without a final newline,** where git prints `\ No newline at end of
  file`, must not become a line of text → Task 1 test `does not show git's
  no-newline marker as a line`.
- **Lines that look like diff headers** (`--- a` and `+++ b` in the content, as
  in Markdown front matter) must be read as content → Task 1 test `reads content
  lines that look like headers`. Count lines by the hunk header, not by prefix
  alone.
- **A file in a repository without commits** must work, since every file is
  untracked → Task 1 test `shows every line as added before the first commit`.
- **A symbolic link and a path through one, and `.git/config`** must be refused
  or shown as the link itself, never followed → Task 2 test `refuses .git and a
  path through a symbolic link`.

### Task 1: The engine's diff

**Files:**

- Create: `libs/server/core/git/src/engine/git-diff.ts` (+ `.spec.ts`), a pure
  parser
- Modify: `libs/server/core/git/src/engine/git-engine.ts` (+ spec),
  `libs/server/core/git/src/index.ts`

**Interfaces:**

- Produces:
  - `parseUnifiedDiff(stdout: string): DiffLine[]`, with `DiffLine = { type:
    'context' | 'added' | 'removed'; oldLine: number | null; newLine: number |
    null; text: string }`.
  - `GitEngine.diff(workingCopy: string, path: string): Promise<FileDiff>`, with
    `FileDiff = { kind: 'text'; lines: DiffLine[]; complete: boolean;
    lineEndingsOnly: boolean } | { kind: 'binary'; oldSize: number | null;
    newSize: number | null } | { kind: 'too-large' }`. Sizes come from `git
    cat-file -s HEAD:<path>` and `lstat`; `null` means that side does not exist.
