# Find Panel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Plan 39 of [the design pass index](2026-10-30-00-design-pass.md):
**Find** opens a compact find and replace panel, as in VS Code and WebStorm,
that floats over the top right of the editor (never over the preview), slides
in, and stands out on a brighter surface. Replace is behind a chevron.

**Architecture:** In `web/code-editor`. A custom panel passed to `search({ top:
true, createPanel })` replaces CodeMirror's default one. It is plain DOM built
with DOM methods (CodeMirror panels are DOM, not Angular), driven by
`@codemirror/search`'s query state and commands. Labels come in through a facet
set from `EditorStateOptions`, because the library has no Transloco; the editor
pane passes translated labels. CSS in `editorTheme` makes the top panel an
absolutely positioned overlay.

**Tech Stack:** CodeMirror 6 (`@codemirror/search`, `@codemirror/view`), Vitest
(jsdom), Playwright.

**Spec:** [design](../specs/2026-10-30-islands-design-pass-design.md) Per page:
Repository screen (Find panel). ED-11, NF-13.

## Global Constraints

- The shared constraints of [the index](2026-10-30-00-design-pass.md) apply.
- **Find row**, start to end: chevron toggle (shows/hides the replace row,
  `aria-expanded`), find field, **Match case**, **Whole word**, **Regular
  expression** toggles (`aria-pressed`, icons `case-sensitive`, `whole-word`,
  `regex`), the counter ("1 of 3", "No results"), **Previous** (`arrow-up`),
  **Next** (`arrow-down`), **Close** (`close`).
- **Replace row**: replace field, **Replace** (`replace`), **Replace all**
  (`replace-all`).
- Keys: `Mod-f` opens with the find row and focuses the field; `Mod-h`
  (Windows/Linux) / `Mod-Alt-f` (macOS) opens it expanded and focuses the
  replace field _(design's call)_; `Enter` / `Shift-Enter` in the find field go
  to the next / previous match; `Enter` in the replace field replaces the
  current match; `Esc` closes and focuses the editor. Read-only states hide the
  replace row and the chevron.
- **Overlay**: `.cm-panels-top` is `position: absolute`, at the top end of the
  editor (`inset-inline-end: var(--ui-space-3)`), `inline-size: min(28rem,
  100% - 2 * var(--ui-space-3))`, `--ui-surface-raised`, `--ui-shadow-popover`,
  radius `0 0 var(--ui-radius-popover) var(--ui-radius-popover)`, no border; the
  text never moves when it opens.
- **Slide-in**: `transform: translateY(-100%)` → `none` over
  `--ui-duration-base` with `--ui-easing-standard`; none with reduced motion
  (the token is 0).
- **Counter** counts at most **1,000** matches and then shows "1,000+" _(plan's
  call, so a 1 MB file stays responsive)_; it is recomputed on query and
  document changes, and announced with `aria-live="polite"`.
- Every control has an accessible name from the labels; icon buttons also have
  `title`.

## Review Focus

- **An invalid regular expression** (`[`) shows "Invalid expression" in the
  counter, highlights nothing and never throws (Task 2 test).
- **A 1 MB file and a one-letter query** stays under one frame per keystroke in
  the field: the 1,000 cap (Task 2 test asserts the counter text "1,000+" and
  that counting stops at the cap).
- **Replace all with an empty replacement** deletes every match as one undoable
  change (Task 2 test: one `undo` restores the text).
- **Opening Find while the panel is open** focuses and selects the find field
  rather than opening a second panel (Task 2 test).
- **The panel in a narrow editor** (Split at 30 %, or 320 px) fits inside the
  editor and wraps the replace buttons rather than overflowing (Task 3
  screenshot).

### Task 1: Labels and the panel's DOM

**Files:**

- Create: `libs/web/code-editor/src/code-editor/search/find-panel.ts`
- Create: `libs/web/code-editor/src/code-editor/search/find-labels.ts`
- Test: `libs/web/code-editor/src/code-editor/search/find-panel.spec.ts`
- Modify: `libs/web/code-editor/src/index.ts`

**Interfaces:**

- `interface FindPanelLabels { find: string; replace: string; toggleReplace:
  string; matchCase: string; wholeWord: string; regexp: string; previous:
  string; next: string; close: string; replaceOne: string; replaceAll: string;
  noResults: string; invalid: string; count: (current: number, total: number,
  more: boolean) => string; }`
- `findLabels: Facet<FindPanelLabels, FindPanelLabels>` (last value wins;
  English defaults so the library works alone).
- `createFindPanel(view: EditorView): Panel` — reads
  `view.state.facet(findLabels)`.
- Icons: built from the sprite like `ui-icon` (an `svg` with a `use` to
  `#<name>`; the sprite URL comes through a second facet, `findIconSprite:
  Facet<string, string>`, set by the editor pane from `ICON_SPRITE_URL`).
