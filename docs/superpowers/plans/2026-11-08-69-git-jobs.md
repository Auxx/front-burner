# Git Jobs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Plan 69 of [the step 4 index](2026-11-08-00-roadmap-step-4.md): what
the push job and `PushService` have that a fetch and a pull need too moves out
of them, so that plans 70 and 77 only add what is theirs.

**Architecture:** A refactor with no new behaviour: today's end-to-end tests and
API stay as they are. Reading a job's state and finding the unfinished network
job become `GitJobs`, which knows every network job type. Resolving credentials
and naming a failure become `JobCredentials` and `networkFailure`.

**Tech Stack:** as before. No new packages.

**Spec:** `docs/architecture/api.md` A-3.2; `docs/architecture/jobs.md` A-6.3;
`docs/requirements/repo-credentials.md` RC-4, RC-19.

## Global Constraints

- The shared constraints of [the step 4 index](2026-11-08-00-roadmap-step-4.md)
  apply.
- The API and the OpenAPI document do not change: `npx nx run
  web-api-client:generate` leaves `git status` clean.

## Review Focus

- **Another user's job, or a job of another type,** is still answered like a
  missing one: `gitJob` must not start serving clones → Task 1 test `answers a
  clone job like a missing one`.
- **A key copy that is never released** would keep a secret in memory, and the
  move must not lose a `release` → the moved test `drops the key copy on done,
  failed and cancelled` stays.
