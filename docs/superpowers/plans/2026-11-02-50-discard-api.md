# Discard API Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Plan 50 of [the step 3 index](2026-11-02-00-roadmap-step-3.md): the
API discards changes to a list of files: a modified or deleted file comes back
from the last commit, and an added one is deleted.

**Architecture:** `GitEngine.discard` reads each path's state from `status`,
inside `WorkingTreeGuard.change`, so that the state cannot change between the
check and the discard. The client always sends the paths it showed, including
for **Discard all**: a change that arrived a moment ago, which the user has not
seen, is never discarded _(plan's call)_.

**Tech Stack:** as before. No new packages.

**Spec:** `docs/requirements/git-advanced.md` (GA-4, GA-23, GA-43, the API for
criterion 8).

## Global Constraints

- The shared constraints of [the step 3 index](2026-11-02-00-roadmap-step-3.md)
  apply.
- Tracked paths: `git --literal-pathspecs restore --source=HEAD --staged
  --worktree --pathspec-from-file=- --pathspec-file-nul`. Added paths: `unlink`
  of the path resolved with `symlinkLeaf: true`. Empty folders left behind stay,
  as after a delete in the tree _(plan's call)_.
- A path in the list that is no longer changed is skipped silently.
- `paths` has 1 to 10,000 entries, each at most 4,096 characters: 50,000 would
  not fit in the server's 2 MB limit on a request body. _(Changed by this plan's
  review.)_
- After a discard: `files.changed` with `folders: 'all'` and `git.changed`.

## Review Focus

- **An added symbolic link to a folder outside the working copy:** the link
  goes, the folder stays → Task 1 test `deletes an added symbolic link, not its
  target`.
- **A path through a symbolic link, and `.git/config`,** are refused before
  anything changes → Task 2 test `refuses .git and a path through a symbolic
  link, and discards nothing`.
- **`:!x` and `*.md` as file names** must only ever name those files → Task 1
  test `reads names as literal paths`.
- **A discard during a merge** is refused, and leaves the files alone → Task 2
  test `refuses a discard during a merge`.
- **A repository without commits:** there is no `HEAD` to restore from, and
  every file is added → Task 1 test `deletes added files before the first
  commit`.
