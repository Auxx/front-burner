# Commit API Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Plan 52 of [the step 3 index](2026-11-02-00-roadmap-step-3.md): the
API commits exactly a list of files with a message, as the commit author that
applies, and refuses a user who has not confirmed their author.

**Architecture:** `GitEngine.commit` is the one way a commit is made. Inside the
working-tree lock it empties anything left in the index (`git reset`), adds
exactly the ticked paths, and commits; on failure it empties the index again, so
the working copy is as it was (GA-43). There is no staging area, so nothing else
may be in the index. The commit is a synchronous request: it is local and short
(GA-3's "may take longer than about 2 seconds" does not apply), and it runs with
the `FRONT_BURNER_GIT_TIMEOUT` limit, since `git add` of a large file can
outlast the 10-second limit of other local commands _(plan's call)_.

**Tech Stack:** as before. No new packages.

**Spec:** `docs/requirements/git-advanced.md` (GA-19, GA-21, GA-42; the API for
criteria 4, 6 and 19); `docs/requirements/commit-author.md` (CA-1, CA-2, CA-5,
CA-6, CA-13; criteria 3, 4, 8); `docs/architecture/git-engine.md` A-5.10.

## Global Constraints

- The shared constraints of [the step 3 index](2026-11-02-00-roadmap-step-3.md)
  apply.
- The commands, in order, with `GIT_AUTHOR_*` and `GIT_COMMITTER_*` set on the
  commit (CA-2):
  1. `git reset -q`, or `git read-tree --empty` when there are no commits;
  2. with no commits, `git symbolic-ref HEAD refs/heads/main` (GA-42);
  3. `git --literal-pathspecs add -A --pathspec-from-file=-
     --pathspec-file-nul`;
  4. `git -c commit.gpgsign=false commit --cleanup=whitespace --no-edit -F -`,
     the message on stdin (GA-21, CA-15).
- The message is refused when empty after trimming, and when over 65,536
  characters _(plan's call)_. Nothing else about it is refused: not a long first
  line (GA-18), and not a line starting with `#` (GA-21).
- `paths` has 1 to 50,000 entries. Paths that are not changes are ignored; if
  none is left, the answer is `409 nothing-to-commit`.
- A user who has not confirmed gets `409 commit-author-not-confirmed` (CA-13),
  checked before the lock.

## Review Focus

- **Staged content left by a crash** must not slip into the commit → Task 1 test
  `commits only the listed paths, even with something else in the index`.
- **A failing commit** (for example a name git refuses) must leave nothing
  staged → Task 1 test `empties the index when the commit fails`.
- **`user.name` and `author.name` in `.git/config`** must lose → Task 1 test
  `AC-GIT-001.4`.
- **A file that is deleted on disk** must be committed as a deletion, and a file
  whose name is `:!x` must only ever name that file → Task 1 tests `commits a
  deletion` and `reads names as literal paths`.
- **A second commit request while the first runs** waits in the lock, and then
  finds nothing to commit → Task 2 test `a repeated request answers
  nothing-to-commit`.
